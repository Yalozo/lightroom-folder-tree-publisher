# Changelog

Versions below were developed locally; this file does not imply that they have been published to GitHub.

## 0.8.0

- Prepare English/Russian documentation, contribution instructions, issue/PR templates, CI checks, and reproducible release packaging.
- Add developer, public contact details, GitHub/email/license buttons, and localized labels to the Plug-in Manager.
- License the project under GPL-3.0-only.

## 0.7.0

- Russian and English translation dictionaries with English fallback.
- Translator guide and localization checks.

## 0.6.0

- Video publishing through Lightroom's standard video export pipeline.

## 0.5.1

- Use `withWriteAccessDo` when marking publications for update after collection settings change.

## 0.5.0

- Per-collection path settings: flat mode, prefix/suffix, trimming, depth limit, and sample preview.

## 0.4.0

- Regular/smart published collections, nested sets, and shared-file reference checks.

## 0.3.2

- Folder/export icon and Plug-in Manager description.

## 0.3.1

- Reveal the publication destination in Finder/Explorer instead of looking for a remote URL.

## 0.3.0

- Store publication identity in Lightroom; stop creating `.ftp-owner` sidecars.

## 0.2.0

- Obtain source roots from the Lightroom catalog folder hierarchy.

## 0.1.0

- Initial folder-tree publication, repeat publishing, collision checks, and optional Trash removal.
