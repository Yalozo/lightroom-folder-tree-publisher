# Folder Tree Publisher

![Folder Tree Publisher](FolderTreePublisher.lrplugin/icon.png)

Публикация фото и видео из **Lightroom Classic** на диск с сохранением иерархии папок каталога и настройками пути для каждой обычной или смарт-коллекции.

**Бета-версия:** автотесты проверяют Lua-логику и имитируют вызовы SDK. Совместимость с конкретными версиями Lightroom и ОС, реальное кодирование видео и весь интерфейс ещё требуют проверки. Плагин предназначен для Lightroom Classic.

## Установка и обновление

1. Скачайте **FolderTreePublisher ZIP с номером версии** из раздела Releases репозитория. Не путайте его с автоматически создаваемым архивом исходного кода.
2. Распакуйте архив в постоянную папку.
3. Откройте **Файл → Диспетчер плагинов → Добавить** и выберите `FolderTreePublisher.lrplugin`.
4. В модуле **Библиотека**, на панели **Службы публикации**, выберите **Настроить** рядом с Folder Tree Publisher.
5. Укажите отдельную существующую папку назначения, настройте формат, размер, качество и метаданные.
6. Сохраните службу, добавьте снимки в коллекцию и нажмите **Опубликовать / Publish**.

Для обновления замените папку плагина и перезапустите Lightroom. Настройки коллекций и идентификаторы публикаций сохраняются. Отдельные Python или Lua для использования плагина не нужны.

## Структура папок

Исходный корень указывать не нужно: плагин читает верхние папки каталога. Например, верхняя папка `Фото` и оригинал `/Users/me/Pictures/Фото/2026/Поездка/IMG_001.CR3` дают:

```text
<папка назначения>/Фото/2026/Поездка/IMG_001--123.jpg
```

`123` — ID фотографии в каталоге. Чтобы сохранить имя `IMG_001.jpg`, отключите добавление ID. ID помогает различать виртуальные копии и файлы с одинаковыми именами.

Если несколько верхних папок каталога имеют одинаковые имена, плагин сообщает об ошибке. Покажите родительские папки в Lightroom, чтобы получить различимые имена. Изменение верхних папок может изменить пути при повторной публикации.

## Коллекции

Правый клик по службе позволяет создать обычную опубликованную коллекцию, смарт-коллекцию с правилами Lightroom или набор коллекций. Вложенные наборы служат для организации интерфейса; их имена не добавляются к пути на диске.

В диалоге создания/редактирования коллекции доступны:

| Настройка | Назначение |
| --- | --- |
| Сохранять иерархию / Всё в одну папку | Сохранить либо убрать исходные папки |
| Подпапка перед иерархией | Например `Клиенты/Анна` |
| Убрать уровней в начале/конце | Удалить часть исходной иерархии |
| Оставить первых уровней | Ограничить оставшуюся глубину; 0 — без ограничения |
| Подпапка после иерархии | Например `JPEG` перед именем файла |

Порядок: убрать начало → убрать конец → ограничить глубину → добавить подпапки. Настройки не меняют имена файлов и не наследуются от наборов. Предпросмотр показывает условный пример, а не выбранный снимок.

После сохранения параметров ранее опубликованные файлы отмечаются для обновления. Нажмите **Publish**. После успешной записи по новому пути прежняя копия перемещается в корзину, если на неё больше не ссылается другая коллекция.

Одна фотография в нескольких коллекциях с одинаковым путём использует общую копию; разные пути дают отдельные копии. Формат и качество общие для всей службы.

## Видео

В настройках службы, в секции **Видео**, включите **Включать видеофайлы / Include Video Files** и выберите формат и качество. Перекодирует Lightroom; плагин копирует результат с фактическим расширением. Поддержка кодеков определяется Lightroom. Правила пути, ID, повторной публикации и удаления действуют и для видео.

## Обновление и удаление файлов

Используйте отдельную папку назначения для каждой службы. Исходные и выходные корни не должны пересекаться. Не публикуйте в одну папку из разных каталогов или служб.

Связь между фотографией и файлом хранится в Lightroom; `.ftp-owner` больше не создаются. Существующий файл без соответствующей записи публикации не перезаписывается. Не подменяйте управляемые копии посторонними файлами: принадлежность определяется сохранённым путём, а не содержимым.

По умолчанию удаление из публикации оставляет копию на диске. При включённой опции удаления копия перемещается в корзину в ходе публикации, только если на путь больше не ссылается другая коллекция. Пустые папки остаются. Если корзина недоступна на сетевом томе, операция завершается ошибкой.

После переноса оригиналов или изменения верхних папок при необходимости используйте **Mark to Republish**. Старые `.ftp-owner` версий до 0.3 удаляются при повторной публикации только при совпадении UUID. Общего сканирования диска нет.

При ошибке замены плагин пытается восстановить прежний файл, но операция не гарантирует восстановление после отключения питания. Оставшиеся `.ftp-new` или `.ftp-backup` сохраните до выяснения причины сбоя.

## Ограничения и обратная связь

Сетевые ресурсы должны быть подключены как обычные папки. Не реализованы FTP/SFTP, экспорт фотооригиналов вместе с XMP, резервное копирование Smart Preview и импорт настроек Jeffrey's Folder Publisher.

Сообщайте об ошибках через **Issues**: версия плагина, Lightroom и ОС, параметры и точный текст ошибки. Убирайте личные данные со скриншотов. Перед большой публикацией проверьте несколько файлов в отдельной папке назначения.

Русский и английский интерфейс выбирается по языку Lightroom. Другие языки используют английский текст; существующие названия коллекций и пользовательские пути не переводятся.

Это самостоятельная реализация по мотивам [Jeffrey's Folder Publisher](https://regex.info/blog/lightroom-goodies/folder-publisher), без включения его кода или файлов Adobe SDK; проект не связан с Jeffrey Friedl или Adobe.
